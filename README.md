# 🎉 Venue Vibe

**Venue Vibe** is a smart venue recommendation web application built using **React** for the frontend and **Node.js** for the backend. It helps users find the best places for events based on their preferences. The app integrates AI through **Gemini API** and uses the **Bing Image Search API** to fetch relevant venue images.

---

## 🚀 Features

- Venue recommendation based on event type, location, and guest count
- Real-time venue suggestions
- Image fetching via Bing API
- AI-enhanced logic with Gemini
- Clean and interactive UI

---

## 🛠 Tech Stack

- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **APIs**: Google Gemini API, Bing Image Search API
